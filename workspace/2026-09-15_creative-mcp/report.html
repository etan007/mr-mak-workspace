只连接任务需要的工具

入门仓库没有启用任何 MCP 配置。这份候选清单列出了可以着手的方向。技能是一份说明文件；连接为代理提供工具。安装其中一个不会顺带安装另一个。

工具与来源适用场景类型
Blender Lab MCP将代理连接到正在运行的 Blender 会话。按照 Blender 当前的插件和服务器说明操作。MCP；可选的编辑器连接
Higgsfield for Blender使用该服务商的 Blender 插件运行其图像、视频和 3D 工作流。编辑器插件；需单独账号
Higgsfield CLI在终端中运行服务商工作流。附带的 Higgsfield 工作流说明了如何查看命令和保留输出。CLI；需单独账号
Unity MCP将代理连接到 Unity 项目的一个社区方案。请先确认支持的编辑器版本。社区 MCP
Godot MCP用于 Godot 项目和编辑器任务的社区桥接。社区 MCP
VibeUE一个 Unreal Engine 代理工具方案。请选择与编辑器版本匹配的分支。编辑器集成
img2threejs根据参考图进行程序化 Three.js 重建的技能工作流。完整技能已随附在此。技能；不是 MCP 连接
fal.ai 托管 MCP用你自己的 fal.ai 账号查看模型 schema 并运行生成。附带的 fal 技能涵盖队列恢复和本地交付。托管 MCP；按量计费 API
fal-mcp-server原始配置文章中提到的社区 fal 服务器，可替代托管连接。社区 MCP；自备密钥

检查你自己的机器

  1. 打开 MCP 侧栏，查看项目配置与全局配置。
  2. 选择当前任务所需的编辑器或服务商。
  3. 阅读其最新安装说明，并在支持的情况下在本项目中配置。
  4. 启动编辑器，或用你自己的账号完成认证。
  5. 运行一次只读连接检查，例如列出当前场景或可用的模型 schema。
  6. 在请求付费生成或场景编辑前，先阅读相关技能。
