# 我的梦想游戏：Mr. Mak 64

一个设定在漂浮天空岛（Sky Islands）上的小型第三人称平台跳跃游戏。Mr. Mak 是一只
戴灰色毛线帽、背棕色背包的小白猪。第一个世界是一段穿过草地岛屿和小村庄的攀登，
主路线下方藏有一个秘密。

## 关卡约定

- 示例引擎是 Unity；编辑前先确认接收者的项目。
- 跑、跳、二段跳、攻击和跳跃攻击。
- 收集 100 颗金色马甲纽扣，并通过不同挑战赢得五顶高礼帽。先把第一版实现做小，
  再扩展路线。
- 使用宽容的第三人称镜头和易读的低多边形美术方向。
